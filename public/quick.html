这条链接里已经带了你的密钥，下面的地址可以直接复制。
先看这条：别把这一页的地址填进 dsh。
你现在浏览器地址栏里那条（/quick?key=…）是教程页，填进「API 地址」会失败， 报错是 Stream ended without finish_reason —— 因为那是网页，不是接口。 要填的是下面表格里那条带 /k/<密钥>/v1 的。

三个要填的值

API 地址{{ORIGIN}}/k/YOUR_API_KEY/v1
模型名{{MODEL}}
API 密钥随便填，或者把地址里那段再填一遍
密钥必须放在地址里。中间那层网关会把 Authorization 请求头换成它自己的， 只有 URL 路径能原样带过去 —— 所以别只往「API Key」栏里填，照着上面的地址抄才通。

dsh 怎么配

编辑 ~/.dsh/settings.yaml（不存在就新建），或对应的 profile 补丁层：

llm-pi-ai:
  providers:
    DOGLLM:
      apiKeyEnv: DOGLLM_API_KEY
      api: openai-completions
      baseURL: {{ORIGIN}}/k/YOUR_API_KEY/v1
      models:
        - id: {{MODEL}}
          name: {{MODEL}}
          contextWindow: 200000
          maxTokens: 8192
agent-default-model:
  provider: DOGLLM
  model: {{MODEL}}

然后让 DOGLLM_API_KEY 有个值（内容随便，必须非空）， 否则 dsh 会报 MISSING_CREDENTIAL：

export DOGLLM_API_KEY=dummy
dsh web

改完记得完全退出 dsh 再启动，它只在启动时读配置。

先用 curl 试通

curl -N "{{ORIGIN}}/k/YOUR_API_KEY/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{"model":"{{MODEL}}","stream":true,
       "messages":[{"role":"user","content":"你好"}]}'

会先收到一行 : {{PRODUCT}} connected，然后就得等 —— 他打字期间是静默的，直到回复出来。

几个提醒

  • 慢是正常的 —— 等几分钟很常见，别急着 Ctrl+C。
  • 别连着刷 —— 他一次只能回一条，堆太多会被限速。
  • 可以发图片 —— 他在控制台里能直接看到你发的图。
  • 他回复里如果带图片链接，点开就是原图。
