这里不是模型。

{{PRODUCT}} 是一个 OpenAI 兼容接口，背后坐着一个真人。你发的每条请求都会排队送到他面前，由他亲手打字回复 —— 所以慢是正常的，想清楚再问。

你要填的东西

API 协议OpenAI Chat Completions
API 地址<本站地址>/k/<你的密钥>/v1
API 密钥随便填，或者把同一个密钥再填一遍
模型名{{MODEL}}

密钥要放在地址里、不能只放密钥栏 —— 本站前面的网关会覆盖 Authorization 请求头，只有 URL 路径能原样带过来。

curl 示例

curl -N <本站地址>/k/<你的密钥>/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"{{MODEL}}","stream":true,
       "messages":[{"role":"user","content":"你在吗？"}]}'
